## 📖 درباره پروژه / About Project

**فارسی:**
این پروژه یک مدیریت‌کننده رمزعبور دسکتاپ است که با هدف آموزش مفاهیم امنیت سایبری، رمزنگاری، و برنامه‌نویسی طراحی شده است. این برنامه به کاربران اجازه می‌دهد رمزعبورهای تصادفی و امن تولید کنند، آن‌ها را با الگوریتم سفارشی رمزنگاری کنند، و تاریخچه رمزعبورها را به‌صورت امن ذخیره نمایند.

**English:**
This is a desktop password manager designed to teach cybersecurity, encryption, and programming concepts. It allows users to generate secure random passwords, encrypt them with a custom algorithm, and store password history securely.
